# Идея проекта: RAG-ассистент по Python

## Проблема
Новичкам сложно быстро находить ответы по Python. Документация большая, поиск не всегда точный.

## Цель проекта
Создать чат-бота, который отвечает на вопросы по Python, используя только загруженные документы, и показывает источник.

## Для кого проект
- Начинающие программисты
- Студенты

## Какие данные использую
- **Источник**: Статьи с Habr по Python
- **Объем**: 1000+ статей
- **Формат**: JSON

## Критерий успеха
- [ ] Бот отвечает на 3 вопроса по Python
- [ ] Бот говорит "не знаю" на вопрос не из документов
- [ ] Показывает источники

## Как проверить
1. Запустить streamlit run app/main.py
2. Задать вопрос по Python
3. Проверить ответ и источник
